# 测试指南

betterLogisticsSpeed 没有自动化测试：仓库无测试源码，`build.gradle` 也没有注册回归任务（`test` 只是 Java 插件的默认空任务）。验证策略是**编译通过 + 实机手测**；每次变更后至少执行 `gradle classes` 与 `gradle deploy`（见 AGENTS.md）。

## 手测清单

按功能覆盖。第 1、2 项为每次改动后必测，其余按改动范围选择。

1. **加载与设置**
   - 模组正常加载，`设置 → 模组 → Better Logistics Speed` 打开且四个设置项齐全。
   - vanilla 且无 OverlayCompatBridge 时，设置页出现红色兼容提示（`bls.overlay.missing`）。
2. **悬停面板增强（原版路径）**
   - 悬停有物品流速的物流建筑，原版每秒流速行下方出现"滑动平均(10s)"行与物品图标。
   - "总吞吐"行随设置开关显示/隐藏；小数位数设置（1–2）生效。
   - 窗口内样本不足时显示 `...`；悬停非物流建筑或放置方块时扩展行隐藏、不残留。
3. **MI2U 路径**
   - 安装 MI2-Utilities-Java 并启用 `replaceTopTable`：滑动平均行出现在 MI2U 重制的悬浮信息栏内。
   - 关闭 `replaceTopTable` 后回退原版路径；两条路径不会同时出现两份扩展行。
4. **多节点标记**
   - `;` 标记当前悬停节点，toast 提示编号；重复标记同一节点重置其采样。
   - 最多 12 个节点，超限有 toast 提示；`'` 删除鼠标悬停的列表行；窗口底部"全部清除"生效。
   - OverlayUI 窗口"物流速率"持续显示总速率与各物品速率，内容宽度跟随父窗口。
5. **世界内编号标记**
   - 已标记建筑绘制旋转方框与编号，编号与列表顺序一一对应。
6. **采样隔离**
   - 同时标记两个节点，各自速率独立显示，互不串扰。
7. **自动清理**
   - 建筑失效/拆除、换图、Reset 后，无效标记自动移除，注入行隐藏。
8. **设置热更新**
   - 修改长窗口时长（2–60s）立即生效并重置采样；开关与文案改动无需重启游戏。
9. **发版前**
   - `gradle classes` + `gradle deploy` 通过，`dist/` 与 `../构建/betterLogisticsSpeed/` 四件产物齐全。
